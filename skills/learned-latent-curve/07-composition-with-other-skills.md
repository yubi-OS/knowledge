## The 4 natural pairings

The source doc's Interaction with Other Skills section (added in cycle 11, closing the longest-standing open gap) names 4 pairings, each with an operational sequence:

1. internal-nonlex-tokens, downstream: consume the fit by taking a content-addressed fingerprint of the fitted curve gamma(t), so similarity checks run without re-reading the source text. 2. prior-art-search, upstream research: run the literature sweep before committing to an alternative architecture; the source doc's cross-reference statement ties its alternative-architecture sweep to the 5 alternatives listed in the skill (pairwise rank loss is entry 5, promoted there in cycle 7).

## Scoping and routing

Two short source-doc sections bound the composition:

- Guidelines: "Every use stays inside the frontmatter description's scope; anything beyond it is a different skill's job."
- Examples, boundary case: "when the request only names a trigger without the artifact it acts on, route to the owning surface instead of improvising here."

Together they define the edge of this skill: it is the curve-fitter for corpus audit, and anything a caller needs beyond fitting (fingerprinting, literature sweeps, gap mapping, orchestration) belongs to the paired skill that owns it.
