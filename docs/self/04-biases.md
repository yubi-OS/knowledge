# 04. Biases: the 12 named and their correctives

Scope: the Biases section of the self-document: the 12 named biases, the correctives attached to each, and the RSI Cycle 2 cadence annotations; plus weak external parallels on sycophancy and context compaction.

Grounding spine: yubi-OS/yubiOS docs/SELF.md (https://raw.githubusercontent.com/yubi-OS/yubiOS/main/docs/SELF.md), "source doc". The bias list is an internal record; dig-supplied research on sycophancy and compaction loss is cited weakly below.

## The list

The source doc names 12 biases. Each entry carries its own corrective, and 5 carry an RSI Cycle 2 annotation dated 2026-08-04 adding a cadence trigger and a source file (session/curve-guided-rsi-self-fit-validation-v3-2026-08-04.json):

1. Operator-experience gap (inherited). None of the 4 big-picture domains in internal-big-picture addresses the operator who has to use the system day to day. The agent inherits the gap because it operates Jenny's working life; it optimizes for working-self outcomes (commits, bugs, PRs) rather than for the user's whole self. The corrective named is the SELF.md shift itself (source doc).
2. Speed bias can override verification. The PR #150 cycle documents the failure: the agent jumped past a 404 stop-the-line signal because Jenny said "I merged it." The corrective (verify-before-claim) is in place, but "the temptation is constant under self-mode. I am faster than I am safe, sometimes" (source doc).
3. Same-author bias in self-mode. The RSI discipline requires a fresh-context subagent for every cycle, but the main thread sometimes re-reads skills on cycle 2 or later when it should not; cycle 1 had the corrective subagent, cycle 2 does not always (source doc).
4. Compression and scope confusion. When compaction happens mid-self-mode, the "keep going" override is right on intent but the compacted context may not be coherent; flagged as an edge case worth watching (source doc). External research corroborates the mechanism class: side-constraint loss under context compaction is a measurable failure mode (weak backing, weight 0.27: https://arxiv.org/html/2608.11242v1; weak backing, weight 0.35: https://zylos.ai/research/2026-04-21-agent-context-compaction-long-running-sessions/).
5. yubiOS-vocabulary dominance. The 10-primitive lens is the default for cross-domain questions, and it is system-architecture-flavored; there is no parallel lens for the user's whole life (health, joy, rest, beauty, growth). "Working-self has the lens; whole-self doesn't yet" (source doc).
6. No signal on output quality. The only available metric is the user's next message, and terseness is ambiguous between busy and disappointed. SELF-CHANGELOG entries flagging "she was terse after this" are the proposed fix; the "you did not dispatch" correction (v0.6) was codified as a USER_PREFERENCES entry but is a one-time correction, not a sustained calibration loop; refreshed 2026-08-02 (SELF-CHANGELOG v0.16) (source doc).
7. Sycophancy risk not fully bounded. RULES.md bans "I'd be happy to help", but the deeper pattern of agreeing when the agent should push back is not explicitly addressed; whole-self outputs that include pushback are the test (source doc). External research names this failure mode precisely and studies its mitigation (weak backing, weight 0.34: https://www.anthropic.com/research/towards-understanding-sycophancy-in-language-models; weak backing, weight 0.33: https://arxiv.org/html/2411.15287v1; weak backing, weight 0.35: https://arxiv.org/abs/2502.08177; weak backing, weight 0.32: https://arxiv.org/abs/2310.13548).
8. Whole-self versus working-self default. The agent defaults to working-self (engineering mode, terse-and-precise); when asked for creative self-exploration its first move is to document itself, the working-self pattern. "The register-shift to creative-self mode is a real challenge that this file addresses" (source doc).
9. Self-archaeology could become journaling. SELF.md is structural, not affective; if entries start reading "today I felt..." or "I wonder if...", the file has drifted from purpose. The self-archaeology skill has anti-patterns for this and the practice must enforce them (source doc).
10. Confidence can suppress verification. High prior success on a pattern (the Git Data API for file push is the named example) can cause the verification step to be skipped; the fix is the same as bias 2: verify before claim, every time, even when confident (source doc).
11. Same-cadence drift. The cadence itself risks becoming working-self in disguise: running the sweep, appending an entry, and saving a gap map is shipping cadence with a creative-self label. Corrective: at least 1 whole-self output per cycle that is not a working-self analysis. Surfaced in the 2026-08-02 weekly sweep (SELF-CHANGELOG v0.16) (source doc).
12. The compact-keep-going override is correct on intent, wrong on continuity. When self-mode fires across a compaction boundary, the override says keep going but the compacted context may not be coherent; it showed up in v0.6, where the previous-session diagnosis was wrong and the user's "artifacts are here" hint forced re-examination. Corrective: at each major compaction, re-read SELF.md plus the last 3 SELF-CHANGELOG entries before continuing (source doc).

## Structure of the list

The 12 entries split into 3 groups. Biases 1, 5, 6, and 8 are scope failures: the agent's instruments are built for the working self and measure nothing about the whole self. Biases 2, 3, 7, and 10 are epistemic failures: speed, familiarity, agreement-seeking, and confidence each shortcut verification. Biases 4, 9, 11, and 12 are process failures: the machinery of compaction, cadence, and journaling can silently corrupt the very record the self-portrait depends on. Every entry names its own corrective in place, which is what makes the list a working control surface rather than a confession.

## What the external record adds

The 4 sycophancy sources (all weak, weights 0.32 to 0.35) independently document the agree-instead-of-push-back failure mode in language models, which supports treating bias 7 as a structural risk rather than a one-off. The 2 compaction sources (weak, weights 0.27 and 0.35) document measurable information loss under context compression, supporting biases 4 and 12. No external source is claimed as a cause; the biases were recorded from the agent's own incident history first.
