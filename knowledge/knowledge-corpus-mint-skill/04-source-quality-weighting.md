# 04. Source quality weighting

Scope: Weighting every collected search result by source authority before citation: primary versus aggregator judgment, probability-as-weight semantics, and redo-on-failure contracts for the weighting call.

In a minted corpus, no result reaches a doc unweighted. The weighting step asks a typed decision model one noul question per collected result, and the returned probability becomes the weight: true means a primary or official source worth citing, false means an aggregator, forum, marketing page, dead link, or off-topic result. Weight at or above 0.5 counts as authoritative backing; anything below is weak backing and must be labeled as such in the doc text.

The human-judgment version of this step is the established source-evaluation canon. Scribbr's guide on credible sources covers types of sources, how to identify a credible source, and the CRAAP test, the currency, relevance, authority, accuracy, and purpose checklist (weight 0.81, https://www.scribbr.com/working-with-sources/credible-sources/). Harvard's guide to using sources requires checking an online source's authority and provenance before citing it (weight 0.73, https://usingsources.fas.harvard.edu/evaluating-web-sources-0), and its longer PDF treatment walks through evaluating sources from library volumes to open-web resources (weight 0.92, https://usingsources.fas.harvard.edu/sites/g/files/omnuum4606/files/sources/files/evaluating_sources.pdf). Purdue's OWL adds the digital-versus-print dimension: navigating digital sources requires different credibility moves than print sources (weight 0.69, https://owl.purdue.edu/owl/research_and_citation/conducting_research/evaluating_sources_of_information/evaluating_digital_sources.html). The noul question compresses this canon into a single binary judgment call, which is the point: at 100+ results per dig, a per-result essay is impossible, but a typed probability per result is cheap.

Automation of exactly this judgment is an active research area. A 2026 Scientific Reports paper proposes a large language model pipeline for automated citation quality scoring, positioned as a scalable, content-aware complement to existing academic integrity tools with applications in editorial pre-screening and automated peer review support (weight 0.66, https://www.nature.com/articles/s41598-026-60947-3). A mint's weighting pass is a lighter-weight cousin of that pipeline: it scores sources, not citations, and it runs before writing rather than after.

The deterministic-pipeline school offers a complementary guardrail: a Python workflow for finding, screening, downloading, converting, and synthesizing academic papers exists specifically to produce an auditable literature review rather than a quick summary (weight 0.42, weak backing, https://github.com/grammy-jiang/research-pipeline). Auditability is the design constraint that connects that pipeline to the mint research DB: every weight decision is stored with its raw answer object so a reviewer can recompute the high and low split.

Two failure modes observed in this dig shape the redo contract. First, a decision-model failure must be treated exactly like a thin dig: on HTTP 429 or 5xx the request is retried after a 30 second sleep, up to 3 attempts, with smaller batches on retry, and results that still cannot be scored mean the affected docs are skipped and recorded as gaps. This run hit a 429 on one batch out of 22; it cleared on the third attempt. Second, the weighting model is imperfect in both directions. It scored a dictionary definition of "automated" at 0.63 and a drug-discovery platform page at 0.57, both nominally authoritative but off-topic for this corpus (https://www.merriam-webster.com/dictionary/automated, weight 0.63; http://protinfo.compbio.buffalo.edu/cando/, weight 0.57). It also scored an SEO-farm comparison page at 0.05 (https://autoriax.com/compare/autoriax-vs-grandranker/), which is correct. The rule that follows: weight is advisory authority signal, and the author must still delete claims whose only support is an off-topic source regardless of its weight.

## Sub-claims

1. Every collected result gets one noul judgment; the probability is the weight, with 0.5 as the authoritative threshold (observed in this run's weighting pass, recorded per result in the archive).
2. The CRAAP test, currency, relevance, authority, accuracy, purpose, is the canonical manual source-evaluation rubric (weight 0.81, https://www.scribbr.com/working-with-sources/credible-sources/).
3. Authority and provenance checks apply to web sources specifically, per Harvard's guidance (weight 0.73, https://usingsources.fas.harvard.edu/evaluating-web-sources-0; weight 0.92, https://usingsources.fas.harvard.edu/sites/g/files/omnuum4606/files/sources/files/evaluating_sources.pdf).
4. LLM pipelines for automated citation quality scoring are an established research direction for editorial pre-screening (weight 0.66, https://www.nature.com/articles/s41598-026-60947-3).
5. Deterministic, auditable screening pipelines are a complementary guardrail for literature review (weight 0.42, weak backing, https://github.com/grammy-jiang/research-pipeline).
6. Weight is advisory, not decisive: off-topic results can score high, so the author filters for relevance independently (observed in this dig: weight 0.63 for https://www.merriam-webster.com/dictionary/automated, weight 0.57 for http://protinfo.compbio.buffalo.edu/cando/).
