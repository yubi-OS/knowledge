# 01 Null-Standardized Corpus Audit

Scope: why a corpus audit compares a measured corpus against matched null corpora, how null distributions are generated by permutation and randomization, and how a z-style score plus a decibel-style magnitude turns "does this corpus have structure?" into a number.

## The problem a null solves

A measurement taken from a corpus (a coverage count, a curve fit, a signal power) means nothing on its own. The frequentist move is to ask: what would this measurement look like if there were nothing there? Every measurement or observation is a mixture of signal and noise, and an important objective of data analysis is to identify the signal by filtering out the noise [1](https://dtkaplan.github.io/Lessons-in-statistical-thinking/L13-Signal-and-noise.html) (weight 0.63). Detector design makes this explicit: you assume the null hypothesis is true and use p-values to estimate how likely an observation is due to noise rather than a real effect [2](https://www.imperial.ac.uk/media/imperial-college/research-centres-and-groups/astrophysics/public/icic/data-analysis-workshop/2016/NoiseVsSignal_ES_0.pdf) (weight 0.61). In geophysical data analysis the same framing appears as "finding a signal in our data that is different from the noise", tested by comparing observed sample data against a null hypothesis [3](https://kls2177.github.io/Climate-and-Geophysical-Data-Analysis/chapters/Week2/signal2noise.html) (weight 0.73).

A statistical hypothesis test is the general method of statistical inference used to decide whether data provide sufficient evidence to reject a particular hypothesis, typically via a calculated test statistic [4](https://en.wikipedia.org/wiki/Statistical_hypothesis_test) (weight 0.15, weak backing).

## Generating the null by permutation

The practical way to build a null distribution when you have no analytic model is resampling. Randomization procedures "can be used as a null model", generating a distribution of the value of interest that is expected under the null; permutation variants trade generality for computational efficiency, for example the serial test versus a global test [5](https://dshizuka.github.io/networkanalysis/06_permutations.html) (weight 0.73). The permutation test is a nonparametric method that tests the null hypothesis that two groups come from the same distribution [6](https://www2.stat.duke.edu/~ar182/rr/examples-gallery/PermutationTest.html) (weight 0.77). Shuffling labels is the standard mechanism for generating the null in applied settings [7](https://bookdown.org/kmbm92/Applied-Biostats/perm1.html) (weight 0.64).

Once the null distribution exists, the p-value has a direct definition: "the smallest level at which the null hypothesis can be rejected, i.e., the probability under the permutation distribution of observing a test statistic at least as extreme as the observed test statistic" [8](https://katsevich-teaching.github.io/stat-9610-notes/permutation-test.html) (weight 0.71). Concretely, you count the number of null test statistics as or more extreme than the observed statistic and divide by the total number of null statistics calculated [9](https://www.jwilber.me/permutationtest/) (weight 0.61).

## Null-standardized scores

With a saved null distribution in hand, the natural next step is to visualize it and locate the observed statistic within it; this is exactly how teaching materials introduce the null-standardized reading of a test statistic [10](https://stat20.berkeley.edu/spring-2026/3-generalization/10-hypothesis-tests/tutorial.html) (weight 0.79). The z-score is the standardized position of the observed value inside that null distribution. A companion magnitude measure expresses how far above the null the signal carries, in decibel-like units; design-of-experiments practice treats a high signal-to-noise ratio as a property a well-designed test should have, with power estimated from the design's properties [11](https://www.afit.edu/stat/statcoe_files/Best%20Practice%20SNR%20for%20DOE%20final.pdf) (weight 0.59).

Two implementation choices matter for reproducibility. First, the null must be matched to the corpus: the randomization must preserve whatever the measurement is supposed to be invariant under (for a column-permutation null, row and column counts; for an iid null, marginals), otherwise the z-score measures the wrong invariance [5](https://dshizuka.github.io/networkanalysis/06_permutations.html) (weight 0.73). Second, the null must be fixed and auditable: the null distribution is data, not a judgment call [10](https://stat20.berkeley.edu/spring-2026/3-generalization/10-hypothesis-tests/tutorial.html) (weight 0.79).

## Application in the Jev Corpus engine

In the Jev Corpus engine the audit path (`v2Corr`, `curveball`, `nullStats`, `dbc`) ports this pattern: a corpus's measured structure is compared against curveball and column-permutation nulls, and the audit emits a null-standardized z score plus a dBc magnitude, with a published anchor (z 12.13 mapping to +21.68 dBc) kept as a fixed test fixture. The results are data: the audit never acts on its own verdict, and a published anchor value is pinned so the implementation can be parity-tested against the reference rather than re-derived.
