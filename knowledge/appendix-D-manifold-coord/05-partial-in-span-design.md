# 05. Partial-in-span target design

Scope: designing targets that mix in-span and out-of-span components so topology signal separates from capacity signal, including least-squares floors on the combined target.

## The projection fact that sets the floor

The least squares regression function is obtained by finding the orthogonal projection of the data vector onto the subspace spanned by the basis functions (https://web.ics.purdue.edu/~ibilion/www.zabaras.com/Courses/BayesianComputing/LinearModelsOfRegression-PartA.pdf, weight 0.6820). This single property drives everything about partial-in-span target design. When a target is decomposed into one component inside the basis span and one component outside it, least squares fits the in-span component exactly and contributes nothing to the out-of-span component; the achievable fit on the combined target is a weighted blend determined by the two components' shares of the target's signal. The standard derivation for linear basis models is elementary: linear basis models can model more complex relationships than simple linear regression models, and the least squares solution can be derived relatively simply for the linear basis models (https://codingowen.github.io/blog/2024/10/22/basis_functions_and_OLS/, weight 0.5293). Ordinary least squares with scikit-learn's LinearRegression is the standard tool for computing such fits (https://scikit-learn.org/stable/auto_examples/linear_model/plot_ols_ridge.html, weight 0.8394).

## Why partial-in-span targets are needed

The problem a benchmark faces is attribution. If a target is fully in one arm's span and outside the other's, the comparison measures span membership, which is inductive bias, but says nothing about how the arms behave when both must extrapolate. If a target is outside both spans, neither arm reaches a meaningful level and the comparison is uninformative. The literature on extrapolation confirms the failure mode is real and general: many machine learning models perform well when making predictions within the training data range, but often struggle when required to extrapolate beyond it (https://arxiv.org/pdf/2511.22794, weight 0.6789). Symbolic regression using genetic programming is prone to unreliable behaviour in extrapolation, which motivated a study of whether adding synthetic data helps (https://arxiv.org/abs/2511.22794, weight 0.8189).

A partial-in-span target splits the difference. By weighting an in-span component against an out-of-span component in a fixed ratio, the designer fixes the least squares floor on the combined target in advance. The measured fit of each arm then decomposes into the guaranteed in-span share plus whatever the arm can do with the out-of-span share. An arm whose measured fit sits near the floor is fitting exactly its in-span component; an arm above the floor is recovering part of the out-of-span component, which is the topology signal.

## Design considerations drawn from the sources

1. The weighting ratio is the dial. Because the floor on the combined target follows from orthogonal projection onto the span (https://web.ics.purdue.edu/~ibilion/www.zabaras.com/Courses/BayesianComputing/LinearModelsOfRegression-PartA.pdf, weight 0.6820), the designer chooses the in-span versus out-of-span signal shares by choosing component weights. A pure in-span target would let the advantaged arm reach a perfect fit and would not test extrapolation; a pure out-of-span target would let neither arm reach a meaningful level. A fixed blend is the deliberate middle.
2. Extrapolation beyond the training range is where models degrade (https://arxiv.org/pdf/2511.22794, weight 0.6789), so the out-of-span component functions as a controlled extrapolation test embedded in an interpolation task.
3. Verification of the span claims should be done numerically before the benchmark runs. Fitting each target component against each arm's design matrix by least squares and recording the coefficient of determination is direct evidence for the in-span and out-of-span labels, consistent with the OLS tooling above (https://scikit-learn.org/stable/auto_examples/linear_model/plot_ols_ridge.html, weight 0.8394).
4. Synthetic augmentation studies evaluate across multiple benchmark datasets with several model families acting as both teacher and student models (https://arxiv.org/html/2511.22794v1, weight 0.7549); the analogous practice for span design is to verify floors across several target blends rather than one.
