# 001 - tpm2 (`tpm2`)

**Scope:** tpm2(1): A single small executable that combines the various tpm2-tools much like a BusyBox that provides a fairly complete environment for any small or embedded system.
**Upstream Manpage:** `man/tpm2.1.md` in `tpm2-software/tpm2-tools` ([tpm2-software/tpm2-tools: man/tpm2.1.md  -  Official Upstream Manpage](https://github.com/tpm2-software/tpm2-tools/blob/master/man/tpm2.1.md), weight 0.9920).
**Multiplexed Invocation:** `tpm2 [OPTIONS]` or `tpm2 tpm2 [OPTIONS]` ([tpm2 - tpm2-tools - Read the Docs](https://tpm2-tools.readthedocs.io/en/latest/man/tpm2.1/), weight 0.9870).

## 1. Command Overview & yubiOS Role

`tpm2` is an official command in the `tpm2-tools` TSS2 CLI suite ([tpm2-software/tpm2-tools: man/tpm2.1.md  -  Official Upstream Manpage](https://github.com/tpm2-software/tpm2-tools/blob/master/man/tpm2.1.md), weight 0.9920). In yubiOS (`bootc` + `mkosi` immutable images and initrd environments), the multiplexed `tpm2` binary provides all 102 TPM 2.0 subcommands inside a single ELF executable (`tpm2 <subcommand> [options]`), minimizing initramfs footprint during early-boot fTPM (`tpm_ftpm_tee`) and `swtpm` verification. ([tpm2 - tpm2-tools - Read the Docs](https://tpm2-tools.readthedocs.io/en/latest/man/tpm2.1/), weight 0.9870)

**tpm2** [*OPTIONS*] [*ARGUMENTS*] ([tpm2 - tpm2-tools - Read the Docs](https://tpm2-tools.readthedocs.io/en/latest/man/tpm2.1/), weight 0.9870)

## 4. Description

**tpm2**(1) - To ease installation of tpm2-tools in initrd or embedded systems
where size-optimization and limited resources are important, it is convenient to
have a single executable that can dispatch the various TPM2 functionalities
specified by the argument which is one of the available tool names.

The options and arguments that follow are either the **common options** or those
specific to the **tool name**.

It is important to note that individual tools with prefix **tpm2_** can still be
invoked, however, they are now soft-linked to this **tpm2** executable. And so
unlike BusyBox, full functionality of the individual tools is available in the
executable. For example: **tpm2_getrandom 8** can alternatively be specified as
**tpm2 getrandom 8**. ([tpm2-software/tpm2-tools: man/tpm2.1.md  -  Official Upstream Manpage](https://github.com/tpm2-software/tpm2-tools/blob/master/man/tpm2.1.md), weight 0.9920)

## 6. Examples

### Get 8 rand bytes from the TPM
```bash
tpm2 getrandom 8 | xxd -p
```

### Send a TPM Startup Command with flags TPM2\_SU\_CLEAR
```bash
tpm2 startup -c
```

**returns** (`man/common/returns.md`): Tools can return any of the following codes: - 0 - Success. - 1 - General non-specific error. - 2 - Options handling error. - 3 - Authentication error. - 4 - TCTI related error. - 5 - Non supported scheme. Applicable to tpm2_testparams.
