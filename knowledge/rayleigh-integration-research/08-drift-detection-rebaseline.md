# 08 - Frozen frames and re-baselining: drift detection with a Ky Fan gap

**Scope:** embedding and corpus drift detection and re-baselining: frozen PCA frames, explained-variance shortfall as a drift signal, and when to rebuild a baseline.

## What a frozen frame is, formally

Principal component analysis computes, for a given dataset and parameter k, the k-dimensional subspace through the origin that minimizes the average squared reconstruction error (weight 0.85, [Stanford CS168 lecture 8](https://web.stanford.edu/class/cs168/l/l8.pdf)). The reference implementation documents the two quantities an instrument needs: components sorted by decreasing explained variance, and explained_variance_, the amount of variance explained by each selected component, estimated with n_samples minus 1 degrees of freedom (weight 0.94, [scikit-learn PCA documentation](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)).

Freezing a frame means keeping the baseline's top-k components fixed and re-evaluating them on later data instead of refitting. The evaluation is a Rayleigh-Ritz reading: the frozen axes are a test subspace, so their captured variance on a new covariance is an upper-bounded test value, never above the new top-k sum (see docs 01 and 02). The gap between the frozen-frame trace and the true top-k sum is the honest quantity: 0 on the baseline itself, growing as the corpus's covariance rotates away from the frozen directions.

## Drift signals in the embedding-monitoring literature

The embedding monitoring literature frames the same problem in production terms. A practitioner post on monitoring embedding spaces notes the failure mode that motivates structural signals: a feature may remain numerically stable on each individual dimension while the relationships between dimensions shift dramatically, and covers techniques for detecting embedding drift and analysing cluster structure in high dimensions (weight 0.64, [Neel Mishra](https://neelmishra.github.io/blog/mlops/monitoring/monitoring-embeddings.html)). A course module on unstructured-data monitoring lists the standard toolbox: since embeddings are numerical values, distance metrics, dimensionality reduction, and distribution-level comparisons are all applicable to embedding distribution drift (weight 0.64, [Evidently AI course 3.4](https://learn.evidentlyai.com/ml-observability-course/module-3-ml-monitoring-for-unstructured-data/monitoring-embeddings-drift)).

A practitioner survey of drift detection methods for ML embeddings reports experiments across three labeled datasets (Wikipedia comments, news categories, food reviews) (weight 0.29, weak backing, [Evidently AI blog](https://www.evidentlyai.com/blog/embedding-drift-detection)). A monitoring course page argues that drift detection for embeddings requires moving past simple statistical tests, using distribution distance metrics, dimensionality reduction, and adversarial classifiers together (weight 0.23, weak backing, [apxml](https://apxml.com/courses/monitoring-managing-ml-models-production/chapter-2-advanced-drift-detection/embedding-drift-monitoring)). An operations playbook draws the same distinction the instrument makes: infrastructure monitoring (latency, error rate, throughput, cost) is separate from drift detection on data (weight 0.31, weak backing, [Alvagante](https://alvagante.com/playbook/posts/2025-05-07-monitoring-drift/)).

The PCA-specific drift literature is small but directly on point. A research repository on chemical sensor data asks exactly the diagnostic question the instrument operationalizes: how does drift affect the principal component structure, and what is the relationship between variance explained, discriminative power, and temporal stability (weight 0.60, [github.com/tgrytnes/sensor-drift-pca](https://github.com/tgrytnes/sensor-drift-pca)). The encyclopedia-level characterization of PCA as an eigenvector-based multivariate analysis related to factor analysis is background (weight 0.19, weak backing, [Wikipedia](https://en.wikipedia.org/wiki/Principal_component_analysis)).

## Why the gap reading is honest where a similarity score is not

The drift-detection literature's weakness, visible across the sources above, is that most signals are unsupervised distances with no fixed reference point: a distribution moves relative to what? The frozen frame supplies the reference point for free. Because the frame is fixed, the Ky Fan gap has a signed, deterministic meaning: it measures how much variance the old axes no longer explain on the new corpus. It cannot be gamed by the corpus growing, because the trace normalization removes scale; it cannot flip sign, because Rayleigh-Ritz test values never exceed the true top-k sum; and it is computable without refitting anything.

What the gap does not say is direction. A large gap means the frozen axes explain less of the current corpus; it does not say whether the corpus improved or worsened, and it does not authorize any refit. That is why the instrument uses it strictly as a re-baseline trigger signal: the human judgment call about "this chain has drifted far enough that a new baseline is warranted" is replaced by a measured, monotone quantity with an exact zero point, but the decision to re-baseline remains a judgment, informed by the number.

## The null caveat carried over

The same margin-preserving null machinery that backs the graph statistics does not directly back the frame gap: the gap is a deterministic function of the two covariances, not a random variable over draws, so it has no null distribution and needs none. The instrument's honest-limitation practice (finite mixing not established, resolution floors at 1/(K+1)) applies to the null-backed statistics, not to the gap reading, whose limitation is different: it is only as meaningful as the frozen frame is representative of the baseline it was computed on.
