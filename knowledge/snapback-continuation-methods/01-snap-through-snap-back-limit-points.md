# Snap-through and snap-back: limit points on the load-displacement curve

**Scope:** Snap-through and snap-back as structural instability phenomena: limit points on the load-displacement curve, why load control cannot pass a limit point, the difference between the two jump mechanisms, classic examples (von Mises truss, shallow arches and domes, cylindrical shells), and post-buckling response.

## Limit points on the equilibrium path

A limit point is a point on the equilibrium path where the tangent stiffness vanishes, dP/du = 0: the load-displacement curve reaches a local maximum (upper limit point) or local minimum (lower limit point) of load. For the von Mises truss, the canonical 1 degree-of-freedom model, the equilibrium load P(w) is a single scalar function with exactly this structure: it rises to an upper limit point, decreases through an unstable central branch where the tangent stiffness K_T = dP/dw is negative, crosses zero, reaches a lower limit point, and rises again in the inverted configuration (https://eng-tools.dev/series-e/3_vonmises-truss/, jev weight 0.49). Closed-form analysis shows the limit-point location is purely geometric: the critical bar length l_cr = (B^2 L_0)^(1/3) contains neither E nor A, so geometry sets whether and where a limit point exists, and the material only sets the critical load value. Below a geometric threshold in the rise-to-span ratio H/B the structure is bistable with limit points; above it, the response is monotonic and no snap occurs (same source). This separates a limit-point instability from an Euler bifurcation: the truss snaps even when its stocky bars would never buckle as columns.

## Load control cannot pass a limit point

Under load (force) control, the structure loses equilibrium at an upper limit point: the stable branch ends, the following branch has negative tangent stiffness, and no static equilibrium exists at any higher load until a distant configuration, so the structure jumps dynamically to that distant equilibrium at (approximately) the same load level. This is snap-through: a load-controlled jump between distant equilibria at a limit point. The von Mises truss analysis includes an explicit load-control failure gate showing the solver cannot traverse the K_T < 0 segment, and that the structure jumps to the inverted branch (https://eng-tools.dev/series-e/3_vonmises-truss/, jev weight 0.49). Commercial FE documentation agrees: Creo Simulate defines snap-through as the structure jumping to a distant equilibrium configuration as the load passes a local maximum (https://support.ptc.com/help/creo/creo_pma/r12/usascii/simulate/simulate/inc_snap_thru.html, jev weight 0.49). Displacement control can pass a load limit point because load becomes the dependent variable, but only arc-length continuation traces the full curve including unstable segments (https://fetraining.net/nonlinear-e-learning-course-supplement/snap-though-problem/, jev weight 0.49).

## Snap-back: displacement reversal on the equilibrium path

Snap-back is the complementary mechanism. On deep arches, long cylindrical shells, and other structures with a strongly folded load-displacement curve, the path can turn back in displacement while the load is still changing: the branch reverses so the tangent becomes negative in the displacement direction (dP/du < 0 with the curve folding back on itself). A controlled FE example on a shallow pinned roof shows the sequence on an arc-length solution: the load peaks near 590 N at the snap-through limit point, unloads through zero at about -17 mm deflection, then the roof snaps back, reversing its displacement, while the load reverses direction (to about -400 N) to stabilize the new configuration (https://fetraining.net/nonlinear-e-learning-course-supplement/snap-though-problem/, jev weight 0.49). So snap-back defeats both simple control schemes: load control cannot follow any unstable branch, and displacement control cannot follow a path that reverses in displacement. Only arc-length (Riks) continuation, treating load and displacement jointly, traces the full post-buckling response (https://fetraining.net/nonlinear-e-learning-course-supplement/snap-though-problem/, jev weight 0.49; https://eng-tools.dev/series-e/3_vonmises-truss/, jev weight 0.49).

## Classic examples and post-buckling response

The standard example family is shallow curved structures loaded transversely: the von Mises truss as the minimal discrete model, shallow arches and domes in FE practice, and buckled elasticas.For continuous shallow arches the mechanism depends on slenderness: low modified slenderness gives limit-point snap-through, high slenderness gives an Euler-like bifurcation before the limit point, and beyond a further value no in-plane instability occurs (Pi, Bradford and Uy 2002, Int. J. Solids Struct. 39, 105, classified in https://eng-tools.dev/series-e/3_vonmises-truss/, jev weight 0.49). The interaction between snap-through and Euler instability in shallow structures remains an active research theme (https://www.researchgate.net/publication/309295135_Interaction_between_Snap-Through_and_Eulerian_Instability_in_Shallow_Structures, jev weight 0.50). Post-buckling, the snapped-through configuration is a genuine stable equilibrium, not a failure state: in the roof benchmark it carries induced membrane stresses in addition to bending stresses (https://fetraining.net/nonlinear-e-learning-course-supplement/snap-though-problem/, jev weight 0.49). The jump itself is dynamic and violent even though predicting the limit point and the start and end equilibria is routine quasi-static computation; recent work models the dynamic snap of a buckled elastica with an energy-preserving single degree-of-freedom model validated against experiments and FE simulation (https://arxiv.org/abs/2509.21328, jev weight 0.50).
