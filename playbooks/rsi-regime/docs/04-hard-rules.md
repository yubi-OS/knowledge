# 04 - Hard rules

**Scope:** the 7 hard rules the source doc says must never be silently substituted, why each exists, and the external mathematics behind the ones that rest on published results.

The source doc's own warning frames this section: "silently substituting any of these voids the audit trail" (yubi-OS/yubiOS playbooks/rsi-regime.md). The rules:

1. **Canonical Fibonacci indexing.** phi_golden = (1+sqrt(5))/2. Do not swap it for pi (the Vogel variant) or for (1+sqrt(5))/2 * pi (the Saff-Kuijlaars variant) without explicit renaming (source doc). The mathematics: the Vogel spiral places point n at polar coordinates r_n = c*sqrt(n) and theta_n = n*alpha with alpha a fixed divergence angle (https://mathworld.wolfram.com/VogelSpiral.html, weight 0.68). Which alpha you plug in is a labeling decision, and the regime treats the golden-angle choice as the canonical one; the other two angles are valid point distributions but they are different instruments. Saff and Kuijlaars' 1997 Mathematical Intelligencer paper "Distributing many points on a sphere" is the reference for the (1+sqrt(5))/2 * pi variant (https://link.springer.com/article/10.1007/BF03024331, weight 0.58), and its Semantic Scholar record confirms the Fibonacci point-set strategy for spherical quadrature (https://www.semanticscholar.org/paper/Distributing-many-points-on-a-sphere-Saff-Kuijlaars/61e0cc7213, weak backing, weight 0.48). A Mathematics Stack Exchange discussion of why golden-angle spirals distribute points evenly also notes a caveat the regime has internalized: Vogel's model obscures the generating curves, which is why the regime insists on explicit renaming when a variant is used (https://math.stackexchange.com/questions/1934101/why-does-a-golden-angle-based-spiral-produce-evenly, weak backing, weight 0.19).
2. **Condon-Shortley normalization for Y_3^3** with K = sqrt(245/(64pi)). Do not drop the phase (source doc). See 05-math-conventions.md for the external grounding.
3. **Test both (l=128, m=256) and (l=256, m=128) orderings in every cycle.** The skill's gate is the higher PC1+PC2 of the two (source doc). This is a symmetry check on the azimuthal basis parameterization; the source doc records it as a hard rule rather than a preference.
4. **i = t.** The Fibonacci index IS the parameter. No lookup tables (source doc). This is the rule that keeps the corpus manifold-aware: item identity is position on the sphere, not a rank in a table.
5. **Never substitute latitude-longitude for Fibonacci sampling** (source doc). The playbook's own rationale is that the ablation answers "Fibonacci vs lat-long" and the two are not equivalent. External corroboration that sampling scheme choice changes measured properties of point sets comes from the Saff-Kuijlaars line of work on distributing points on the sphere (https://link.springer.com/article/10.1007/BF03024331, weight 0.58).
6. **Fresh-context subagent per cycle in self-mode.** Cycle 2 and later run in main-thread context re-introduce the author bias that cycle 1 mitigated (source doc). This is a process rule, not a math rule; it is what keeps the loop's hypotheses independent of the agent that wrote the corpus.
7. **doubt-driven-development is a per-hypothesis supplement, not a substitute** for the fresh-context subagent (source doc). Adversarial review of a hypothesis does not reproduce the context isolation the subagent provides.

## Why rules rather than defaults

Rules 1, 2, and 5 pin parameters that a well-meaning implementer could "improve" silently. The regime's position, stated in the source doc's header for the section, is that the audit trail is the artifact: a loop that swapped its basis or its normalization mid-stream would still produce numbers, but the numbers would no longer be comparable across cycles, which defeats the fixpoint rule itself.
